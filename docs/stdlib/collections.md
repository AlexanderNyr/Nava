## `sum_of(values: Vec(i64)) -> i64`

`sum_of(values)` — the sum of a vector of whole numbers.

| Contract | |
|---|---|
| Precondition | none |
| Postcondition | the sum of every element, and `0` for an empty vector; the addition is the checked one, so a sum that does not fit in an `i64` stops the program rather than wrapping round |
| Cost | O(vec_len(values)) |
| Pure | yes |

**Example**, which must be true:

```nava
let values: Vec(i64) = vec_new()
vec_push(values, 1)
vec_push(values, 2)
collections::sum_of(values) == 3
```

**Example**, which must be true:

```nava
let empty: Vec(i64) = vec_new()
collections::sum_of(empty) == 0
```

**Example**, which must be true:

```nava
let mixed: Vec(i64) = vec_new()
vec_push(mixed, -5)
vec_push(mixed, 5)
collections::sum_of(mixed) == 0
```

**Documented failure**, which must happen:

```nava
let big: Vec(i64) = vec_new()
vec_push(big, 9223372036854775807)
vec_push(big, 1)
print(collections::sum_of(big))
```

The program stops with `i64 overflow in +`.

## `contains_all(haystack: Vec(i64), wanted: [i64]) -> bool`

`contains_all(haystack, wanted)` — is every wanted value in the vector?

| Contract | |
|---|---|
| Precondition | none |
| Postcondition | true when each element of `wanted` appears at least once in `haystack`; true for an empty `wanted`, because there is nothing missing; multiplicity is not counted, so wanting the same value twice needs it in the vector once |

## `count_distinct(values: Vec(i64), seen: HashSet(i64)) -> i64`

`count_distinct(values, seen)` — how many different values the vector holds.

| Contract | |
|---|---|
| Precondition | none |
| Postcondition | every element of `values` is added to `seen`, and the result is `set_len(seen)` — the size of the set as it stands after the call, so a set that already held values counts them too; the caller's set is left with the values in it, which is what makes a second call answer the same number |
| Cost | O(vec_len(values)) expected set operations |
| Pure | no |

**Example**, which must be true:

```nava
let values: Vec(i64) = vec_new()
vec_push(values, 3)
vec_push(values, 1)
vec_push(values, 3)
let seen: HashSet(i64) = set_new()
collections::count_distinct(values, seen) == 2
```

**Example**, which must be true:

```nava
let empty: Vec(i64) = vec_new()
let seen: HashSet(i64) = set_new()
collections::count_distinct(empty, seen) == 0
```

**Example**, which must be true:

```nava
let values: Vec(i64) = vec_new()
vec_push(values, 7)
let seen: HashSet(i64) = set_new()
set_add(seen, 7)
collections::count_distinct(values, seen) == 1
```

## `keys_of(table: HashMap(str, i64), out: Vec(str)) -> void`

| Contract | |
|---|---|
