## `is_continuation(byte: i64) -> bool`

`is_continuation(byte)` — is this byte a UTF-8 continuation byte?

| Contract | |
|---|---|
| Precondition | `byte` is a byte value, 0..255 in practice |
| Postcondition | the result is `true` exactly for the range 128..191 |
| Cost | O(1) |
| Pure | yes |

```nava
text::is_continuation(128) && text::is_continuation(191)
```

**Example**, which must be true:

## `sequence_width(value: str, index: i64) -> i64`

`sequence_width(value, index)` — the length in bytes of the UTF-8 sequence at `index`, or 0 when it is malformed.

| Contract | |
|---|---|
| Precondition | `0 <= index < bytes_len(value)`; the caller checks the range, and the byte read stops the program when it does not hold |
| Postcondition | the result is 1, 2, 3 or 4 for a well-formed sequence and 0 for a malformed one — overlong forms, surrogates and anything above U+10FFFF are malformed |
| Cost | O(1) |
| Pure | yes |

**Example**, which must be true:

```nava
text::sequence_width("a", 0) == 1 && text::sequence_width("\u00e9", 0) == 2
```

**Example**, which must be true:

```nava
text::sequence_width("\u20ac", 0) == 3
```

**Documented failure**, which must happen:

```nava
text::sequence_width("abc", 7)
```

The program stops with `byte index 7 is out of bounds for a string of 3 bytes`.

## `is_valid_utf8(value: str) -> bool`

`is_valid_utf8(value)` — is the whole string well-formed UTF-8?

| Contract | |
|---|---|
| Precondition | none |
| Postcondition | the result is `true` exactly when every sequence in the string is well-formed, so the builtin `chars_len` would accept it |


`code_points(value)` — how many code points the string holds.

| Contract | |
|---|---|
| Precondition | none |
| Postcondition | the result is the number of well-formed sequences, or -1 when the string is not valid UTF-8; the builtin `chars_len` stops the program instead |
