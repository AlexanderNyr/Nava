## `is_sorted(values: [i64]) -> bool`

`is_sorted(values)` — is every element at least the one before it?

| Contract | |
|---|---|
| Precondition | none |
| Postcondition | the result is `true` exactly when no adjacent pair decreases |
| Cost | O(n) for n elements, and O(1) for an empty or one-element array |

**Example**, which must be true:

```nava
let values: [i64] = [1, 2, 2, 3]
sort::is_sorted(values)
```

**Example**, which must be true:

```nava
let empty: [i64] = []
sort::is_sorted(empty)
```

**Example**, which must be true:

```nava
let backwards: [i64] = [2, 1]
!sort::is_sorted(backwards)
```

## `insertion_sort(values: [i64]) -> void`

`insertion_sort(values)` — sort `values` in place, ascending. equal elements keep their relative order one sort, not the fastest one

| Contract | |
|---|---|
| Precondition | `values` is a writable array, so the call needs an array created here |
| Postcondition | the array is a permutation of what it held, `is_sorted` accepts it, and |
| Cost | O(n^2) comparisons and moves; the routine exists to give the language |

**Example**, which must be true:

```nava
let values: [i64] = [3, 1, 2]
sort::insertion_sort(values)
values[0] == 1 && values[1] == 2 && values[2] == 3
```

**Example**, which must be true:

```nava
let empty: [i64] = []
sort::insertion_sort(empty)
len(empty) == 0
```

## `binary_search(values: [i64], wanted: i64) -> i64`

`binary_search(values, wanted)` — where `wanted` sits in a sorted array. and is not detected `wanted` is absent

| Contract | |
|---|---|
| Precondition | `is_sorted(values)` holds; searching an unsorted array is a caller error |
| Postcondition | the result is a valid index whose element equals `wanted`, or -1 when |
| Cost | O(log n) comparisons for n elements |

**Example**, which must be true:

```nava
let values: [i64] = [1, 2, 3]
sort::binary_search(values, 2) == 1
```

**Example**, which must be true:

```nava

sort::binary_search(values, 9) == -1
```

**Example**, which must be true:

```nava
let empty: [i64] = []
sort::binary_search(empty, 1) == -1
```
