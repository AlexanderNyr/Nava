## `flag_in(values: [str], word: str) -> bool`

`flag_in(values, word)` — does this word appear in these arguments?

| Contract | |
|---|---|
| Precondition | none |
| Postcondition | true exactly when some element of `values` is equal to `word`, compared byte for byte; `false` for an empty array, for an empty `word` that no element is, and no element is skipped |
| Cost | O(len(values) × bytes_len(word)) |
| Pure | yes |

**Example**, which must be true:

```nava
args::flag_in(["--verbose", "a"], "--verbose")
```

**Example**, which must be true:

```nava
!args::flag_in(["--verbose", "a"], "verbose")
```

**Example**, which must be true:

```nava
!args::flag_in([], "--verbose")
```

## `value_in(values: [str], word: str, fallback: str) -> str`

`value_in(values, word, fallback)` — the word after `word`, or the fallback.

| Contract | |
|---|---|
| Precondition | none |
| Postcondition | the element that follows the **first** occurrence of `word`, and `fallback` when `word` is absent or is the last element — a flag with nothing after it has no value rather than an empty one, so a missing argument cannot be mistaken for an argument that is empty |
| Cost | O(len(values) × bytes_len(word)) |
| Pure | yes |

**Example**, which must be true:

```nava
args::value_in(["--count", "3"], "--count", "1") == "3"
```

**Example**, which must be true:

```nava
args::value_in(["--count"], "--count", "1") == "1"
```

**Example**, which must be true:

```nava
args::value_in([], "--count", "1") == "1"
```

**Example**, which must be true:

```nava
args::value_in(["--a", "x", "--a", "y"], "--a", "z") == "x"
```

## `count() -> i64`

`count()` — how many arguments the program was given.

| Contract | |
|---|---|
| Precondition | none |
| Postcondition | the number of words after the program's own name; 0 when it was started with none. The contract examples run with the command line `--count 3 name`, because a module about a command line cannot be demonstrated without one |
| Cost | O(1) |
| Pure | no |

**Example**, which must be true:

```nava
args::count() == 3
```

## `get(index: i64) -> str`

`get(index)` — one argument, by position.

| Contract | |
|---|---|
| Precondition | `0 <= index < count()`; a position outside that range stops the program |
| Postcondition | the word at that position, exactly as the process received it |
| Cost | O(1) |
| Pure | no |

**Example**, which must be true:

```nava
args::get(0) == "--count"
```

**Example**, which must be true:

```nava
args::get(2) == "name"
```

**Documented failure**, which must happen:

```nava
print(args::get(9))
```

The program stops with `argument index 9 is out of bounds for 3 arguments`.

## `flag(word: str) -> bool`

`flag(word)` — does the program's own command line contain this word?

| Contract | |
|---|---|
| Precondition | none |
| Postcondition | true exactly when some argument equals `word`, byte for byte; the same answer `flag_in` gives for the arguments as an array |
| Cost | O(count() × bytes_len(word)) |
| Pure | no |

**Example**, which must be true:

```nava
args::flag("--count")
```

**Example**, which must be true:

```nava
!args::flag("--verbose")
```

## `value(word: str, fallback: str) -> str`

`value(word, fallback)` — the argument after this word, or the fallback.

| Contract | |
|---|---|
| Precondition | none |
| Postcondition | the first argument that follows `word`, and `fallback` when `word` is absent or last; the same answer `value_in` gives for the arguments as an array |
| Cost | O(count() × bytes_len(word)) |
| Pure | no |

**Example**, which must be true:

```nava
args::value("--count", "1") == "3"
```

**Example**, which must be true:

```nava
args::value("--missing", "1") == "1"
```
