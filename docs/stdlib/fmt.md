## `repeat(text: str, times: i64) -> str`

`repeat(text, times)` — `text` written `times` times.

| Contract | |
|---|---|
| Precondition | `times >= 0`; a negative count is a mistake rather than a request, and the result is empty |
| Postcondition | the result is `text` concatenated `times` times, and it is empty when `times` is 0 or `text` is empty |
| Cost | O(bytes_len(text) × times) bytes copied, in O(log times) calls to `str_concat`, because the text is doubled rather than appended one copy at a time |
| Pure | yes |

**Example**, which must be true:

```nava
fmt::repeat("ab", 3) == "ababab"
```

**Example**, which must be true:

```nava
fmt::repeat("x", 0) == ""
```

**Example**, which must be true:

```nava
fmt::repeat("", 5) == ""
```

## `f64_fixed(value: f64, decimals: i64) -> str`

`f64_fixed(value, decimals)` — a real number with a fixed number of decimal places.

| Contract | |
|---|---|
| Precondition | `0 <= decimals <= 9`, `value` is finite and `|value| × 10^decimals` fits in an `i64`; those bounds are what the arithmetic needs, and the conversion stops the program when the last one does not hold |
| Postcondition | the result has exactly `decimals` digits after the point, rounded to the nearest and away from zero on a tie; the rounding applies to the binary value the machine holds, so `f64_fixed(1.005, 2)` is `"1.00"` and not `"1.01"`; a value that rounds to zero is written without a sign, so `f64_fixed(-0.4, 0)` is `"0"` |
| Cost | O(decimals) |
| Pure | yes |

**Example**, which must be true:

```nava
fmt::f64_fixed(1.0 / 3.0, 3) == "0.333"
```

**Example**, which must be true:

```nava
fmt::f64_fixed(2.0, 2) == "2.00"
```

**Example**, which must be true:

```nava
fmt::f64_fixed(-2.5, 0) == "-3"
```

**Example**, which must be true:

```nava
fmt::f64_fixed(-0.4, 0) == "0"
```
