## `basename(path: str) -> str`

`basename(path)` — the last component of a path.

| Contract | |
|---|---|
| Precondition | none |
| Postcondition | everything after the last `/`, or the whole path when there is none; a path that ends with `/` has an empty last component, and that is what comes back — this function cuts, it does not tidy |
| Cost | O(bytes_len(path)) |
| Pure | yes |

**Example**, which must be true:

```nava
fs::basename("a/b.txt") == "b.txt"
```

**Example**, which must be true:

```nava
fs::basename("b.txt") == "b.txt"
```

**Example**, which must be true:

```nava
fs::basename("a/b/") == ""
```

**Example**, which must be true:

```nava
fs::basename("") == ""
```

## `dirname(path: str) -> str`

`dirname(path)` — everything before the last `/`.

| Contract | |
|---|---|
| Precondition | none |
| Postcondition | the path without its last component; `.` when the path has no `/`, so `dirname("a.txt")` is `.` and joining it back with `basename` is the same path again; `/` when the last component sits at the root; the empty path has the empty directory |
| Cost | O(bytes_len(path)) |
| Pure | yes |

**Example**, which must be true:


**Example**, which must be true:

```nava

```

**Example**, which must be true:

## `path_join(left: str, right: str) -> str`

`path_join(left, right)` — two paths joined with exactly one `/`.

| Contract | |
|---|---|
| Precondition | none |
| Postcondition | `left` and `right` with one `/` between them, and no `/` of its own when `left` already ends with one or `right` starts with one; an empty `left` gives `right`, an empty `right` gives `left`, and two empty paths give the empty path.  Nothing is normalised: `path_join("a", "..")` is `"a/.."` |
| Cost | O(bytes_len(left) + bytes_len(right)) |
| Pure | yes |

**Example**, which must be true:

```nava
fs::path_join("a", "b") == "a/b"
```

**Example**, which must be true:

```nava
fs::path_join("a/", "b") == "a/b"
```

**Example**, which must be true:

```nava
fs::path_join("a", "/b") == "a/b"
```

**Example**, which must be true:

```nava
fs::path_join("", "b") == "b"
```

**Example**, which must be true:

```nava
fs::path_join("a", "") == "a"
```

## `exists(path: str) -> bool`

`exists(path)` — is there anything at this path?

| Contract | |
|---|---|
| Precondition | `path` is inside a directory granted with `--allow-read`; a path outside every grant stops the program, whatever the answer would have been |
| Postcondition | true when the path exists, as a file or as a directory; false when it does not, including when the directory that would hold it does not exist |
| Cost | O(1) system calls |
| Pure | no |

**Example**, which must be true:

```nava
fs::exists("exists.txt") == false
```

**Example**, which must be true:

```nava
write_file("here.txt", "x")
fs::exists("here.txt")
```

**Documented failure**, which must happen:

```nava
print(fs::exists("../outside.txt"))
```

The program stops with `path_exists denied: '../outside.txt' is outside every permitted directory`.

## `entries(path: str, out: Vec(str)) -> void`

`entries(path, out)` — the names in a directory, appended to a vector.

| Contract | |
|---|---|
| Precondition | `path` is a directory inside a directory granted with `--allow-read` |
| Postcondition | the names of its entries are appended to `out` in **byte order**, which is the same order on every run and every host; `.` and `..` are not entries; a file where a directory was expected stops the program |
| Cost | O(entries × log entries) for the order, O(total name bytes) |
| Pure | no |

**Example**, which must be true:

```nava
write_file("listed.txt", "")
let names: Vec(str) = vec_new()
fs::entries(".", names)
vec_len(names) > 0
```

**Example**, which must be true:

```nava
write_file("listed2.txt", "")
let again: Vec(str) = vec_new()
fs::entries(".", again)
fs::exists("listed.txt")
```

**Documented failure**, which must happen:

```nava

```

The program stops with `cannot open 'no_such_dir': No such file or directory`.
