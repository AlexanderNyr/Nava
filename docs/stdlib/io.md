## `count_lines(text: str) -> i64`

`count_lines(text)` — how many lines the text has.

| Contract | |
|---|---|
| Precondition | none |
| Postcondition | the result is `1 + the number of '\n' bytes`, which is the number of fields `str_split` would produce; the empty text is one empty line, and a text that ends with `\n` counts the empty line after it |
| Cost | O(bytes_len(text)) |
| Pure | yes |

**Example**, which must be true:

```nava
io::count_lines("") == 1
```

**Example**, which must be true:

```nava
io::count_lines("one") == 1
```

**Example**, which must be true:

```nava
io::count_lines("one\ntwo") == 2
```

**Example**, which must be true:

```nava
io::count_lines("one\ntwo\n") == 3
```

## `read_lines(path: str, out: Vec(str)) -> void`

`read_lines(path, out)` — the lines of a file, appended to a vector.

| Contract | |
|---|---|
| Precondition | `path` is inside a directory granted with `--allow-read`, and the file exists; either failure stops the program with the message below |
| Postcondition | the lines of the file are appended to `out`, and the empty field a final `\n` produces is dropped — so a file written by `write_lines` reads back as the lines it was written from, and an empty file reads back as **one** empty line, exactly as `count_lines("")` says; the whole file is one text of at most 1048576 bytes, the limit `read_file` states |
| Cost | O(bytes_len(file)) |
| Pure | no |

**Example**, which must be true:

```nava
io::write_lines("round_trip.txt", ["a", "b"])
let lines: Vec(str) = vec_new()
io::read_lines("round_trip.txt", lines)
vec_len(lines) == 2
```

**Documented failure**, which must happen:


## `write_lines(path: str, values: [str]) -> void`

`write_lines(path, values)` — a file, one line per element.

| Contract | |
|---|---|
| Precondition | `path` is inside a directory granted with `--allow-write`; the whole text must stay under 1048576 bytes, the limit `write_file` states |
| Postcondition | the file holds the lines in order, each followed by `\n`, so the file ends with a newline; an empty array writes an empty file, and the file is replaced rather than appended to |
| Cost | O(total bytes) |
| Pure | no |

**Example**, which must be true:

**Example**, which must be true:

## `append_line(path: str, text: str) -> void`

`append_line(path, text)` — one more line at the end of an existing file.

| Contract | |
|---|---|
| Precondition | `path` is inside granted directories, the file exists and is readable **and** writable, and the result stays under 1048576 bytes |
| Postcondition | the file holds what it held, then `text`, then `\n`; nothing is rewritten except the file itself, and the previous content is read back exactly as it was stored |
| Cost | O(size of the file) — the whole file is read and written again, because the language has no append mode |
| Pure | no |

**Example**, which must be true:

```nava
io::write_lines("appended.txt", ["a"])
io::append_line("appended.txt", "b")
bytes_len(read_file("appended.txt")) == 4
```

**Example**, which must be true:

```nava
io::write_lines("tail.txt", [])
io::append_line("tail.txt", "x")

```
