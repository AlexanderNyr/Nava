## `seconds_to_millis(seconds: i64) -> i64`

`seconds_to_millis(seconds)` — a number of seconds as a number of milliseconds.

| Contract | |
|---|---|
| Precondition | none |
| Postcondition | `seconds × 1000`, computed with the checked `*`, so a value whose product does not fit in an `i64` stops the program rather than wrapping round; the sign is carried through unchanged |
| Cost | O(1) |
| Pure | yes |

**Example**, which must be true:

```nava
time::seconds_to_millis(2) == 2000
```

**Example**, which must be true:

```nava
time::seconds_to_millis(0) == 0
```

**Example**, which must be true:

```nava
time::seconds_to_millis(-1) == -1000
```

**Documented failure**, which must happen:

```nava
print(time::seconds_to_millis(9223372036854775807))
```

The program stops with `i64 overflow in *`.

## `millis_to_seconds(millis: i64) -> i64`

`millis_to_seconds(millis)` — whole seconds in a number of milliseconds.

| Contract | |
|---|---|
| Precondition | none |
| Postcondition | the milliseconds divided by 1000, truncating **towards zero** — so `2500` is `2`, `-2500` is `-2` and `999` is `0`; the remainder that is dropped is what `millis_in_second` returns |
| Cost | O(1) |
| Pure | yes |

**Example**, which must be true:

```nava
time::millis_to_seconds(2500) == 2
```

**Example**, which must be true:

```nava
time::millis_to_seconds(-2500) == -2
```

**Example**, which must be true:

```nava
time::millis_to_seconds(999) == 0
```

## `millis_in_second(millis: i64) -> i64`

`millis_in_second(millis)` — the part of a millisecond count that is less than one second.

| Contract | |
|---|---|
| Precondition | none |
| Postcondition | `millis` remainder 1000, which is in `0 … 999` for a non-negative value and in `-999 … 0` for a negative one, because the division truncates towards zero; `millis_to_seconds(m) * 1000 + millis_in_second(m) == m` holds for every value |
| Cost | O(1) |
| Pure | yes |

**Example**, which must be true:

```nava
time::millis_in_second(2500) == 500
```

**Example**, which must be true:

```nava
time::millis_in_second(1999) == 999
```

**Example**, which must be true:

```nava
time::millis_to_seconds(2500) * 1000 + time::millis_in_second(2500) == 2500
```

| Contract | |
|---|---|
| Precondition | none |

## `monotonic_millis() -> i64`

`monotonic_millis()` — milliseconds from a point that only moves forward.

| Contract | |
|---|---|
| Precondition | none |
| Postcondition | a reading of the monotonic clock, in milliseconds; readings never decrease, and time the machine spends asleep is not counted, so the difference between two readings measures a duration rather than a change of date. The point it counts from is not specified — only differences are meaningful |
| Cost | O(1) |
| Pure | no |

**Example**, which must be true:

```nava
time::monotonic_millis() >= 0
```

**Example**, which must be true:

```nava
let mark = time::monotonic_millis()
time::monotonic_millis() >= mark
```

## `elapsed_millis(start: i64) -> i64`

`elapsed_millis(start)` — how long it has been since a monotonic reading.

| Contract | |
|---|---|
| Precondition | `start` is a value `monotonic_millis()` answered earlier in this process, or `0` to count from the start of the machine's uptime |
| Postcondition | `monotonic_millis() - start`, computed with the checked `-`; for a mark that was taken earlier the answer is a duration in milliseconds and never negative. A fabricated mark that lies in the future gives a negative number rather than a clamp: the subtraction is what it is, and hiding it would turn a mistake into a measurement of zero |
| Cost | O(1) |
| Pure | no |

**Example**, which must be true:

```nava
let mark = time::monotonic_millis()
time::elapsed_millis(mark) >= 0
```

**Example**, which must be true:

```nava
time::elapsed_millis(time::monotonic_millis()) >= 0
```

**Example**, which must be true:

```nava
let mark = time::monotonic_millis()
let spin = 0
while time::elapsed_millis(mark) < 2 { spin = spin + 1 }
time::elapsed_millis(mark) >= 2
```
